# The inventory that doesn't add up

A fictional bookstore sends a `data/movements.csv` file every night with books coming in and going out. The inventory report is showing wrong numbers and nobody knows why.

## What to do

Write the function `balanceByIsbn(lines)` in `src/inventory.js`. It receives the CSV content (already read as text) and returns an object with the balance of each ISBN.

## What to deliver

- `src/inventory.js` passing the tests
- a `NOTES.md` explaining what you found in the data and where Claude got it wrong, if it did

## How to run

```
npm test
```

Use Claude as much as you like. Open the data file before trusting what this statement says.
